## 🔧 What I do

I come from business and operations, so I start from the decision someone needs to make and work backwards to the system. That usually means a clean data model, deterministic logic for anything that has to be exact, and a model only where there is genuine ambiguity.

- **AI agents with tool use** in Python, built to investigate and propose rather than to decide
- **Retrieval-grounded classification** so answers come from the organization's own rules, not the model's recall
- **Evaluation harnesses** that measure accuracy against labelled data, so prompt changes are evidence-based
- **Workflow automation and integrations** with n8n across CRMs, communication tools and enterprise systems
- **Business intelligence** dashboards that surface exceptions instead of just reporting numbers

## 📌 Featured project

### [OpsFin — AI Operations & Finance Engine](https://github.com/Franciscojcdev/opsfin-engine)

Detects revenue leaks and reconciliation anomalies across two domains from one core. Rules flag the clear-cut cases, a Python agent with tool use investigates the ambiguous ones and proposes a resolution, and a human approves before anything posts. Includes RAG-grounded categorization, an evals harness over a gold-labelled dataset, Slack escalation and a full audit trail.

The part I am most pleased with: when two unpaid schedules match a payment equally well, the agent declines to choose and says why, instead of guessing.

[![OpsFin dashboard](https://raw.githubusercontent.com/Franciscojcdev/opsfin-engine/main/docs/images/dashboard-rentals.png)](https://github.com/Franciscojcdev/opsfin-engine)

`Python` · `Claude API` · `Tool use` · `Pinecone` · `PostgreSQL` · `FastAPI` · `React`
